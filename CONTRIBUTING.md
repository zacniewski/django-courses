# 🤝 Contributing to Django Courses

Thank you for your interest in contributing! This project is a simple but effective example of a Django+React integration.

## 🛠️ Development Workflow

1. **Fork** the repository.
2. **Clone** your fork.
3. **Create a branch** for your feature or bugfix: `git checkout -b feature/amazing-feature`.
4. **Develop**:
   - Follow the existing code style.
   - Add comments for complex logic.
   - Ensure backend tests pass: `cd backend && python manage.py test`.
   - Ensure frontend tests pass: `cd frontend && npm test`.
5. **Commit** your changes: `git commit -m 'Add some amazing feature'`.
6. **Push** to the branch: `git push origin feature/amazing-feature`.
7. **Open a Pull Request**.

## 📝 Code Style Guidelines

- **Python**: Follow PEP 8.
- **JavaScript**: Use ES6+ syntax and functional components where possible.
- **Indentation**: 4 spaces for Python, 2 spaces for JavaScript/HTML/CSS.

## 🐞 Reporting Issues

If you find a bug or have a suggestion, please open an issue with:
- A clear title and description.
- Steps to reproduce (for bugs).
- Expected vs. actual behavior.
